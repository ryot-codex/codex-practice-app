# ディズニー待ち時間メモ（練習用）

スマホで見やすい、シンプルなカード型UIのWebアプリです。  
外部APIは使わず、サンプルデータのみで動作します。

> ⚠️ このアプリに表示される待ち時間は、リアルタイム情報ではありません。すべて練習用のサンプルデータです。

## できること

- 東京ディズニーランド / 東京ディズニーシー / すべて の切り替え表示
- 代表的なアトラクション（合計約30件）の表示
- アトラクションごとに「パーク名・エリア・待ち時間・優先度・子連れ向け」を表示
- ボタンで「待ち時間が短い順」に並び替え
- 条件（待ち時間の短さ + 優先度）をもとに「今おすすめ」を表示
- 現在の表示件数を表示

## 起動方法

このアプリはビルド不要の静的ファイル構成です。

1. このリポジトリを開く
2. `index.html` をブラウザで開く

または簡易サーバーを使う場合（任意）:

```bash
python3 -m http.server 8000
```

その後、ブラウザで `http://localhost:8000` にアクセスします。

## ファイル構成

- `index.html`: 画面レイアウト（注意文、パーク切り替え、表示件数を含む）
- `style.css`: スマホ向けカードデザイン
- `app.js`: サンプルデータ、フィルター、描画、並び替え、今おすすめロジック
