# ディズニー待ち時間メモ

GitHub Pages で公開できる静的Webアプリです。Cloudflare Worker 経由で Queue-Times API の待ち時間を取得します。

> ⚠️ これは東京ディズニーリゾート公式アプリではありません。

## 主要機能

- PARK表示を **Tokyo Disneyland / Tokyo DisneySea / All** に変更
- おすすめ順 / 待ち時間順 の切り替え
- モード切替（通常 / 子連れ / 効率重視 / 休憩向き / すき間時間）
- **Next Move** カード（理由バッジ付き）
- 「次の一手」表現を廃止し、Next Move中心の案内へ統一
- 今日の予定をプルダウン選択式で追加可能
  - Park連動で候補切り替え（ランド / シー / 共通）
  - 「その他」を選ぶと自由入力欄を表示
  - 予定の追加 / 削除
  - 時刻順表示
  - localStorage 保存（リロード後も保持）
  - 次の予定と「あと何分」を表示
- すき間時間モードで残り時間を考慮した候補表示

## 今日の予定機能について

- ショー/パレード時刻の**自動取得は未対応**です。
- 今日の予定は手入力で管理します。
- 入力項目: 予定名 / 時刻 / パーク / カテゴリ / メモ

## デザイン方針

- 公式サイト風の清潔感 + パークガイド感 + ワクワク感を意識
- 淡いブルー、ネイビー、白、シャンパンゴールド中心
- 背景グラデーション、星の装飾、チケット風パネルを採用
- ただし公式ロゴ・公式画像・キャラクター画像は未使用

## API / Worker 構成

GitHub Pages フロントエンド → Cloudflare Worker → Queue-Times API

- `worker.js` は CORS 対応済み中継APIです。
- 今回の改善でも **worker.js は変更していません**。
- Cloudflare Worker や Queue-Times API 連携の仕組みも変更していません。

## 注意表示

- Powered by Queue-Times.com を画面に表示
- 非公式アプリの注意書きを画面に表示
- ショー/パレード時刻は手入力であることを表示

## ファイル

- `index.html`: UI構造
- `style.css`: デザイン
- `app.js`: 表示ロジック・Next Move判定・今日の予定管理
- `worker.js`: Cloudflare Worker（今回未変更）
