# ディズニー待ち時間メモ（練習用）

スマホで見やすい、シンプルなカード型UIのWebアプリです。  
外部APIは使わず、サンプルデータのみで動作します。

> ⚠️ このアプリに表示される待ち時間は、リアルタイム情報ではありません。すべて練習用のサンプルデータです。

## できること

- 東京ディズニーランド / 東京ディズニーシー / すべて の排他的な切り替え表示
- 「おすすめ順」「待ち時間順」の分かりやすい切り替え
- 現在の条件（パーク・並び順）と表示件数の表示
- 「今おすすめ」を専用カードで強調表示
- アトラクションごとに「パーク・エリア・待ち時間・優先度バッジ・子連れ向けラベル」を表示

## 今回のUI改善ポイント

- 白ベース + 余白多めのミニマルデザインへ刷新
- パーク切り替えと並び替えをセグメントコントロール風に分離
- 選択中状態を色・影で明確化し、タップ時の状態変化を分かりやすく整理
- ヘッダー、注意文、一覧の情報設計を見直して縦に自然に読める構成へ改善

## 起動方法

このアプリはビルド不要の静的ファイル構成です。

1. このリポジトリを開く
2. `index.html` をブラウザで開く

または簡易サーバーを使う場合（任意）:

```bash
python3 -m http.server 8000
```

その後、ブラウザで `http://localhost:8000` にアクセスします。

## ファイル構成

- `index.html`: 画面レイアウト（フィルタバー、状態表示、おすすめカードを含む）
- `style.css`: ミニマルUIテーマとスマホ向けカードデザイン
- `app.js`: サンプルデータ、排他的フィルター、並び替え、描画ロジック
